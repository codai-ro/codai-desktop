# Screenshots

This folder holds the screenshots referenced from the README and docs. They
are **not here yet** — we are still collecting real captures from the Windows
build. We will not use mock-ups or generated images; every picture here will be
a genuine screenshot of a released version.

Planned files (names are stable so docs can link to them ahead of time):

| File                    | Shows                                                        |
| ----------------------- | ------------------------------------------------------------ |
| `onboarding.png`        | First run: paste your API key                                |
| `sessions.png`          | Sessions list with role and REMOTE badges                    |
| `session-live.png`      | A live transcript with presence strip and control bar        |
| `run-here.png`          | The _Run here_ panel holding the lease (LOCAL badge)         |
| `ask-card.png`          | A permission ask card: Allow once / Always allow / Deny      |
| `settings-executor.png` | Settings → Executor: approved folders, browser path, budgets |

Want to help? Take a screenshot at 1100×720 (the default window size), redact
any session content or keys, and open a PR.
